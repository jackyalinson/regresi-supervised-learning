# Data

Dataset mentah terdiri dari 1.500.000 observasi, 30 variabel prediktor (X1–X30), dan 1 variabel respons (Y).

File data mentah tidak disertakan dalam repository ini karena ukurannya besar. Jalankan kode dengan menunjuk ke lokasi file `.txt` asli menggunakan argumen `--data`.

Format yang digunakan kode:
- delimiter: tab (`\t`)
- prediktor: `X1` sampai `X30`
- respons: `Y`
